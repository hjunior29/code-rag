O code-rag transforma qualquer pasta de código em um índice semântico local. Você pergunta em linguagem natural; ele responde com o arquivo, a linha e o símbolo exatos — para você ou para o seu agente de IA, via MCP.

100% local · nada sai da sua máquina Agnóstico · qualquer pasta, qualquer modelo 2 comandos · make up + make index

1Indexação: da pasta ao vetor

Quando você roda make index DIR=/sua/base, a pasta é montada read-only dentro do container e passa por este pipeline:

📁

Walk — descoberta de arquivos

Percorre a árvore inteira ignorando o que não é código útil: .git, node_modules, vendor, pastas de build, arquivos de lock e binários. Só arquivos de texto até 512KB seguem adiante.

🌳

Chunking — recorte inteligente

Cada arquivo é recortado em chunks, a unidade que será buscada depois. Python, Go, TypeScript e JavaScript são analisados com tree-sitter (AST real): cada função, método, classe, struct e interface vira um chunk com nome e linhas exatas. Todas as outras linguagens usam janelas de ~100 linhas com sobreposição.

#️⃣

Dedup — hash de conteúdo

Cada chunk ganha um sha256 do seu conteúdo. Se o hash já existe no banco, o embedding antigo é reutilizado — por isso reindexar um projeto que mudou pouco leva segundos, não minutos.

Na prática: primeira indexação do agree-code-rag = 256s · reindexação sem mudanças = 7s
🧮

Embedding — texto vira vetor

Os chunks novos são enviados em batches ao provider configurado, que devolve um vetor (uma lista de números) capturando o significado do código. A dimensão do vetor é auto-detectada — troque de modelo à vontade, o schema se adapta.

💾

Gravação atômica no pgvector

Numa única transação, o índice antigo do projeto é substituído pelos novos chunks + vetores no Postgres com pgvector, indexados com HNSW para busca por similaridade em milissegundos.

2Chunking em ação

O mesmo arquivo, dois destinos: com gramática tree-sitter, o recorte segue a estrutura do código; sem ela, janelas de linhas garantem que nada fique de fora.

🌳 Estrutural (tree-sitter)

python · go · typescript · javascript
class UserService: def get_user(self, id): return self.db.find(id) def validate_token(token): return jwt.decode(token)
class · UserService method · UserService.get_user function · validate_token

📄 Janela de linhas (genérico)

rust · java · vue · sql · markdown · yaml · qualquer texto
linhas 1–100 ┐ │ chunk 1 ┘ linhas 86–185 ┐ chunk 2 │ (15 linhas de ┘ sobreposição) linhas 171–270 ┐ chunk 3 ┘ …
block · 1–100 block · 86–185 block · 171–270

3Busca: pergunta vira vizinhança

Sua pergunta também vira um vetor — no mesmo espaço onde vivem os chunks. Buscar é encontrar os vizinhos mais próximos por similaridade de cosseno.

"onde o token é validado?"
auth.py · validate_token
middleware.ts · verifyJwt
session.go · CheckToken

Por baixo dos panos

uma única query SQL resolve
SELECT file_path, name, 1 - (embedding <=> $query) AS score FROM chunks ORDER BY embedding <=> $query LIMIT 10

O operador <=> é a distância de cosseno do pgvector, acelerada pelo índice HNSW. Filtros opcionais de projeto e linguagem entram no WHERE.

4Embeddings agnósticos

5MCP: seu agente de IA como cliente

O servidor expõe as ferramentas via Model Context Protocol em http://localhost:8000/mcp. O Claude Code (ou qualquer cliente MCP) passa a consultar sua base de código sem precisar abrir arquivo por arquivo.

🔍
search_code

Busca semântica por linguagem natural, com filtros de projeto, linguagem e top_k.

🎯
find_symbol

Localiza função, classe ou método pelo nome — match exato primeiro, parcial depois.

🗂️
list_projects

Lista as bases indexadas, com contagem de arquivos, chunks e data da indexação.

Registrar no Claude Code

claude mcp add --transport http code-rag http://localhost:8000/mcp

6O que fica guardado

Três tabelas no Postgres — simples de inspecionar, simples de apagar.

🗂️ projects
  • name text · unique
  • root_path text
  • file_count int
  • chunk_count int
  • last_indexed_at timestamptz
🧩 chunks
  • file_path · lang · kind
  • name ex: UserService.get_user
  • start_line · end_line
  • content o código em si
  • content_sha chave do dedup
  • embedding vector(dim) + HNSW
⚙️ meta
  • embedding_model modelo usado
  • embedding_dim auto-detectada
  • Trocou de modelo? O code-rag recusa misturar vetores incompatíveis e pede um make reset-db.
