Pesquise na sua máquina

Este site explica como o code-rag funciona. Para pesquisar seu código, rode o projeto localmente e indexe uma pasta sua.

No seu terminal
git clone https://github.com/hjunior29/code-rag.git
cd code-rag
make up
make index DIR=/path/to/project
Abrir minha busca local → Ver instruções e prompt de configuração
